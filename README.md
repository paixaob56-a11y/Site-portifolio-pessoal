# 🌐 Site Portfólio Pessoal Responsivo

Um site one-page desenvolvido para apresentar minhas habilidades, projetos e trajetória como estudante de Análise e Desenvolvimento de Sistemas.

### 🎯 Objetivo do Projeto
O objetivo principal foi criar uma presença online profissional para iniciar minha carreira em Desenvolvimento Web e Mobile. 
Como estou em início de carreira, precisava de um espaço para centralizar meus estudos, projetos e formas de contato, substituindo a falta de experiência profissional formal por um portfólio visível.

**Problemas que o projeto resolve:**
1.  Falta de um espaço para mostrar meus projetos e habilidades
2.  Ter um link profissional para colocar no LinkedIn e Currículo
3.  Praticar na prática conceitos de HTML, CSS e Responsividade

---

### 🛠️ Tecnologias Utilizadas
Este projeto foi construído com as tecnologias base do Front-end:

- **HTML5**: Estruturação semântica do conteúdo
- **CSS3**: Estilização, Flexbox, Grid e Design Responsivo para mobile
- **JavaScript**: Interatividade básica e manipulação do DOM
- **Git e GitHub**: Versionamento de código
- **GitHub Pages**: Hospedagem gratuita do site

---

### 📚 O que eu aprendi com essa experiência
Durante o desenvolvimento deste projeto eu consolidei e aprendi:

1.  **Estruturação de Código**: Aprendi a organizar arquivos HTML e CSS de forma limpa e escalável.
2.  **Design Responsivo**: Entendi como usar Media Queries para o site se adaptar a celular, tablet e desktop.
3.  **Versionamento com Git**: Passei a usar commits para salvar versões e o GitHub para publicar o projeto.
4.  **Pensamento de UX**: Tive que pensar na jornada do recrutador: o que ele precisa ver primeiro? Sobre, Projetos, Contato.
5.  **Importância da Documentação**: Percebi que um bom README faz toda diferença para outra pessoa entender meu projeto.
